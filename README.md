# SOS 113

Phiên bản này chỉ thay đổi giao diện theo yêu cầu:
- Xóa toàn bộ chữ, biểu tượng và hình ảnh khác.
- Chỉ giữ lại nút tròn màu đỏ.
- Đổi chữ trên nút từ “GỌI 113” thành “xem”.
- Giữ nguyên chức năng gọi `tel:113` của file gốc.

Đưa 4 file vào GitHub Pages để sử dụng.

Lưu ý: `tel:113` mở chức năng gọi điện của thiết bị. Website không thể tự tạo một kênh trò chuyện trực tiếp riêng với công an; phần thoại được thực hiện qua hệ thống điện thoại/nhà mạng sau khi cuộc gọi được kết nối.
